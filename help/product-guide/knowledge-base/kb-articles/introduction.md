# Experience Manager Guides知識庫

知識庫包含適用於Experience Manager Guides的實用情境導向文章，內容包括核心產品檔案以外的常見設定、自訂和使用案例。

| 類別 | 說明 |
|---|---|
| 製作 | 在編輯器中建立和重複使用內容的秘訣與技巧，包括編輯器自訂、中繼資料管理和內容驗證。 |
| Guides擴充功能框架 | 瞭解如何自訂Experience Manager Guides UI，從開始使用擴充功能框架，到建立自訂元件、Widget，以及檢閱應用程式自訂。 |
| 外部資料Source | 有關將外部資料來源聯結器與Experience Manager Guides整合及設定的指引。 |
| 發佈 | 產生輸出的最佳實務，包括原生PDF、DITA-OT、AEM Sites範本和微服務型發佈設定。 |
| 工作流程 | 設定並使用產生輸出的後置工作流程來自動化步驟。 |
| 翻譯 | 有關如何改善翻譯效能及管理要納入或排除於翻譯之內容的指示。 |
| 使用案例 | 瞭解現實世界的情境，例如條件式內容、使用索引鍵以及在發佈輸出中的內容內容變數。 |

# MCP — 將存取權擴充至受控的技術內容

瞭解模型上下文通訊協定(MCP)如何讓AI支援的體驗透過自然語言請求與AEM Guides安全互動，同時遵守現有的AEM存取控制和許可權。 在本次研討會中，我們將說明MCP架構、組態、驗證及安全性模型，示範目前支援的功能，並探索實際使用案例、目前界限及主要考量事項。 此外也涵蓋AEM as a Cloud Service和內部部署/AMS環境的部署考量事項、示範啟用MCP的使用者端如何與AEM Guides連線，並討論MCP搭配Adobe更廣的AI功能適用之處。

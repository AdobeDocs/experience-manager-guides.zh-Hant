# 設定檔案名稱 {#id214BD010GXA}

本主題涵蓋有關使用DITA檔案的檔案名稱的資訊。 若是以UUID為基礎的系統，您可以選擇自動定義以UUID為基礎的檔案名稱，若是一般系統，您可以控制檔案名稱中允許的有效字元清單。

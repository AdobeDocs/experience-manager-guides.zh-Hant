# 設定用於產生輸出的範本預設集

>[!NOTE]
>
> 自2026.08.0版開始，Experience Manager Guides as a Cloud Service中提供範本預設集。 請聯絡您的客戶成功團隊以啟用此功能。

範本預設集可讓管理員標準化多個DITA map的輸出預設集設定。 您可以定義預設集為範本，並將其套用至與資料夾設定檔相關聯的所有對映，而不是為每個對映個別設定相同的輸出預設集。

此功能可協助您跨專案維持一致的發佈設定，並減少手動設定工作。

## 優點

使用範本預設集具備下列優點：

- 確保跨多個對應的一致發佈設定。
- 消除重複的預設設定，減少手動操作。
- 啟用集中管理輸出預設集設定。

## 支援的輸出型別

所有輸出預設集型別都支援範本預設集，以下除外：

- Edge Delivery Services
- 知識庫
- SCORM

## 建立和管理範本預設集

>[!NOTE]
>
> - 範本預設集只能由&#x200B;**管理員**&#x200B;和&#x200B;**資料夾設定檔管理員**&#x200B;建立和管理。
> - 範本預設集用於配置管理，不直接用於產生輸出。

1. 設定您要用於資料夾的資料夾設定檔。
2. 從對應主控台開啟關聯資料夾的&#x200B;**輸出預設集**。
3. 建立或選取要作為範本的輸出預設集。

   >[!NOTE]
   >
   > 建立或選取要作為範本使用的輸出預設集時，請確保已將其新增到目前的資料夾設定檔中。

4. 從預設集的&#x200B;**選項**&#x200B;選單中選取&#x200B;**設定為範本**。

   ![](assets/template-preset.png){width="650"}

   選取的輸出預設集會被轉換為範本預設集。 範本預設集以範本圖示識別，可區別於一般預設集。 若要移除範本狀態，請隨時從範本預設集的&#x200B;**選項**&#x200B;功能表中選取&#x200B;**取消設定為範本**。

   ![](assets/unset-as-template.png){width="650"}

5. 從範本預設集的&#x200B;**選項**&#x200B;功能表選取&#x200B;**套用預設集變更**，以將更新的預設集設定套用至所選資料夾設定檔中的所有現有對映。

   **套用預設集變更**&#x200B;對話方塊開啟。

   ![](assets/apply-preset-change.png){width="350"}

6. 若要覆寫現有的預設集，請選取&#x200B;**覆寫現有的預設集**&#x200B;核取方塊，然後選取&#x200B;**確定**。 覆寫會更新預設集，但不會修改目標預設集中的「基線」、「條件預設集」、「DITAVAL」、「主題清單」或「發佈內容」設定。 這些設定保持不變。

   會開啟&#x200B;**確認動作**&#x200B;對話方塊，指出套用預設集變更的對應數目。

   ![](assets/confirm-preset-change.png){width="350"}

7. 選取&#x200B;**確定**。

變更會套用至關聯資料夾中所有對應中的所有預設集。

>[!NOTE]
>
> 在相關資料夾中建立新地圖時，範本預設集的本機副本也可以用於該新建立的地圖。


## 輸出產生行為

範本預設集是設定範本，不適合直接發佈。 將預設集標示為範本時：

- 無法使用產生輸出。
- 範本預設集無法用於發佈。
- 如果現有產生的範本預設集輸出是在預設集轉換為範本之前建立的，則仍可存取這些輸出。

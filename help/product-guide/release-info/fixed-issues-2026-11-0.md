# 2026.11.0版本中的已修正問題

本文介紹2026.11.0版Adobe Experience Manager Guides as a Cloud Service中多個區域修正的錯誤。

如需新功能和增強功能的詳細資訊，請檢視[2026.11.0版的新增功能](./whats-new-2026-11-0.md)。

瞭解2026.11.0版[&#128279;](./upgrade-instructions-2026-11-0.md)的升級指示。

## 編輯器2.0

- 使用編輯器中的階層連結選取表格列，並從內容功能表選取&#x200B;**刪除**&#x200B;選項時，只會移除儲存格內容，而不會刪除整列。 (GUIDES-56759)
- 從Microsoft Word貼上表格時，會建立標題列儲存格，但儲存格內容會遺失。 (GUIDES-49847)
- 在移動到編輯器2.0之前建立的檔案中追蹤的變更未出現在&#x200B;**追蹤變更**&#x200B;面板中。 (GUIDES-44777)
- 當程式碼從Microsoft Word或類似的文字編輯器使用Ctrl+V貼到`codeblock`元素中時，分行符號和前導空格會遺失，程式碼會平面化為單行。 (GUIDES-33247)

## 製作

- 統一命令介面啟用時， Adobe Experience Manager Guides標頭也會出現在編輯器和對映主控台中。 (GUIDES-56812)
- 在Assets UI中，會針對非DITA資產顯示DITA專屬動作，例如&#x200B;**檢視來源**、**編輯主題**&#x200B;和&#x200B;**共用UUID連結**。 此外，**共用UUID連結**&#x200B;會為沒有UUID的資產產生無效的連結。 (GUIDES-47043)
- 在「主旨」配置面板中，只會從`navtitle`屬性中挑選顯示標題。 即使同時存在`navtitle`專案，也會忽略它們。 (GUIDES-37722)
- 在「存放庫」面板的&#x200B;**標題檢視**&#x200B;中，名稱較長的檔案一開始不會顯示省略符號。 在檔案上按一下滑鼠右鍵後，檔案右側的省略符號和內容功能表會出現，有時會在熒幕外出現。 (GUIDES-37118)
- 在「條件」面板中，條件會根據其值而非標籤按字母順序排序。 (GUIDES-14593)
- 在輸出範本中，當樣式表（例如layout.css）開啟時，**新樣式** (+)按鈕不會顯示在樣式面板中。 (GUIDES-49448)

## 資產管理

- 當您使用&#x200B;**覆寫現有檔案**&#x200B;選項上傳已修改的檔案時，如果現有檔案沒有Guides UUID且儲存在&#x200B;**後處理的已忽略路徑**&#x200B;下列出的資料夾中，則上傳似乎已完成。 但是，不會覆寫現有檔案，也不會建立新版本。 (GUIDES-55866)
- 在書籤地圖中，當`booktitle`元素包含多個子元素（例如`booklibrary`和`mainbooktitle`）時，會在`dc:title`中繼資料中的值之間新增額外的空格。 (GUIDES-28877)

## 發佈

- 在對應主控台中，為一個對應產生輸出後，開啟另一個對應時，**產生**&#x200B;按鈕會停用。 重新整理瀏覽器會再次啟用按鈕。 (GUIDES-54591)
- 建立目錄時，將特定對應發佈至具有元件對映的AEM網站會失敗並出現錯誤。 (GUIDES-53807)
- 當對應包含具有`navtitle`屬性且沒有`href`屬性的`topicref`元素時，將對應發佈到具有元件對應的AEM網站會失敗。 在刪除產生的網站節點之前，即使元素已移除，後續嘗試也會失敗。 (GUIDES-53707)
- 在包含元件對應的AEM網站輸出中，第2層到第6層的Markdown標題會呈現為第1層標題。 (GUIDES-51134)
- 對於具有元件對應的AEM網站輸出，prolog中繼資料（例如作者、關鍵字和資源ID）會顯示在已發佈輸出的頁面本文中。 (GUIDES-44087)
- 將主題發佈至ServiceNow時，文章本文會包含主題的簡短說明和序言。 (GUIDES-47868)
- 當已在ServiceNow中發佈的主題再次發佈時，會在「草稿」狀態中建立新文章，而非覆寫現有的文章。 (GUIDES-37872)
- 當條件預設集在發佈至Salesforce期間排除主題參考時，即使剩餘的主題成功發佈，輸出產生也會報告為失敗。 (GUIDES-37807)
- 發佈大型對應至Salesforce失敗，並出現閘道逾時錯誤。 (GUIDES-33722)
- 當請求包含超過25個操作時，發佈對應至Salesforce會失敗並出現超過限制的錯誤。 (GUIDES-33721)
- 在地圖儀表板（舊）中，現有條件預設集中的&#x200B;**新增全部**&#x200B;並不會擷取建立預設集後新增或變更的條件值。 (GUIDES-45940)
- **輸出歷程記錄**&#x200B;頁面中包含警告的記錄會顯示綠色圖示，此圖示並不表示出現警告。 (GUIDES-27000)
- 當對應內容中的任何辭彙都未參考到辭彙表專案時，字彙表不會包含在輸出中。 (GUIDES-52964)
- 在附錄中參考的子地圖中的主題會呈現為章節，而非附錄內容。 (GUIDES-52775)
- 當輸出語言設定為中文（簡體）時，部分簡體中文字元會以日文字型轉譯。 (GUIDES-48094)
- 索引專案會遺失子專案（例如`keyword`、`ph`和`sup`）的文字。 因此，某些索引標籤不完整或空白。 (GUIDES-40902)
- 不會保留內嵌`option`元素周圍的空格，導致相鄰的文字出現連線在一起。 (GUIDES-40900)

## 翻譯

- 在「翻譯」頁面上，依&#x200B;**標題**&#x200B;搜尋及排序時，會使用當地語系化的中繼資料值，而非欄中所顯示的標題。 (GUIDES-45396)

## 檢閱

- 在&#x200B;**稽核者**&#x200B;頁面上，在建立或編輯稽核工作期間，預設會啟用&#x200B;**清除選取專案**、**新增稽核者**、**移除稽核者**&#x200B;以及&#x200B;**重新指派稽核者**&#x200B;按鈕，即使未選取任何列。 (GUIDES-35125)
- 在AEM收件匣中，與稽核任務相關的通知，例如任務指派、收到的意見回饋、提及，以及到期或逾期提醒，會在沒有任何專案名稱的情況下顯示。 (GUIDES-10912)
- 在稽核任務中主題的並排檢視中，以刪除線標籤的內容會以不同的格式顯示在兩個檢視中。 (GUIDES-56079)

## 學習內容

- 產生大型課程（通常為300 MB至600 MB）的SCORM輸出需要30分鐘以上的時間，並且失敗時日誌中沒有錯誤詳細資料。 (GUIDES-56101)
- 無法在Experience Manager Guides中設定SCORM輸出的完成條件。 (GUIDES-55520)
- AVIF格式的影像會顯示在編輯器中，但發佈的輸出中會遺失。 (GUIDES-55515)
- `href`屬性會從已發佈輸出中的錨點標籤中移除，因此連結無法點選。 (GUIDES-55514)

## Platform

- 當使用者在資料夾設定檔中被指派為管理員使用者，但不是管理員群組成員時，他們無法成功新增其他管理員使用者。 雖然會顯示成功訊息，但新新增的使用者會在重新整理頁面後消失。 (GUIDES-50144)

## 已知問題

Adobe發現了2026.11.0版的下列已知問題：

## 製作

- 當您從包含相依主題或子對映的範本建立對映時，對映建立可能會間歇性地失敗並出現錯誤，尤其是當伺服器負載較重時。 (GUIDES-58715)

### 編輯器2.0

- **重新整理導覽標題屬性**&#x200B;選項不會將`@navtitle`屬性新增至DITA map中的現有`topicref`元素。 (GUIDES-54348)

**追蹤變更**

當&#x200B;**追蹤變更**&#x200B;開啟時：

- 當包含已刪除內容的元素被重新命名或格式化時，由同一使用者進行的巢狀刪除並不一定合併到單一專案中。 (GUIDES-58429)
- 當其他使用者進行巢狀刪除時，**追蹤變更**&#x200B;面板有時會顯示父專案的不完整內容。 (GUIDES-58428)
- 當您刪除其他使用者插入的內容時，紅色的Gutter標籤不會顯示在左側。 (GUIDES-58418)

### 發佈

- 在原生PDF輸出中，上標和下標格式不會保留在索引專案中。 (GUIDES-58349)
- 當您使用相同的全域預設集來產生不同地圖的輸出時，先前地圖的選取主題可能會影響新地圖的輸出。 (GUIDES-58346)
- 在特定案例中，`<chapter>`同時定義直接`href`目標且該章節包含巢狀`<topicref>`子元素時，發佈書籤有時會導致空白頁面。 (GUIDES-58266)
- 當您從包含未儲存變更的預設集導覽至&#x200B;**輸出歷程記錄**&#x200B;索引標籤時，**儲存**&#x200B;和&#x200B;**產生輸出**&#x200B;按鈕仍可見。 (GUIDES-57989)
- 當為預設集設定發佈後工作流程時，**輸出歷史記錄**&#x200B;中顯示的發佈持續時間不包含工作流程所花費的時間。 (GUIDES-57856)
- 您無法從&#x200B;**輸出歷程記錄**&#x200B;頁面取消原生PDF輸出產生。 (GUIDES-57821)

### 檢閱

- 開啟在2026.08.0或2026.09.0版本中建立的稽核工作有時會導致應用程式錯誤，因為稽核內容包含&#x200B;*任何稽核註解*&#x200B;以及不斷行空格(`&nbsp;`)。 (GUIDES-56583) <br>**因應措施：**&#x200B;完成或關閉在這些版本中建立的所有稽核工作。

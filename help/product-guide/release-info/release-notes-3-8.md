# 發行說明 |Adobe Experience Manager Guides 3.8

**免責宣告**：

*Adobe Experience Manager Guides*&#x200B;先前是以Adobe Experience Manager *的* XML Documentation為品牌。 請注意，檔案中的某些參考資料可能仍會參考先前的品牌，但仍適用於目前的產品。

本發行說明列出適用於Adobe Experience Manager的XML Documentation 3.8.x版中的主要新功能和增強功能。

## 3.8.5版中的新功能和增強功能

### 錯誤修正

3.8.5版本修正的錯誤如下：

- 透過FrameMaker Publishing Server輸出的PDF缺少基準線支援。
- 如果已在AEM中設定各種群組的檔案夾層級許可權，FrameMaker或Ourney的取出和存回API將無法正常運作。
- Assets UI頁面不會顯示內容預覽。
- Assets UI頁面上的「Source」按鈕無法運作。
- 透過Web編輯器的「插入影像」功能插入影像時，插入影像的相對路徑會變更為絕對路徑。
- FMPS預設集下拉式清單不會顯示在最新版本3.8的UI中。
- 當DAM中包含大量資產，且從XML網頁編輯器新增新增我的最愛專案時，我的最愛面板不會顯示。
- 內部重新導向&#x200B;*sling:mapping*&#x200B;無法運作且會顯示長URL （含內部路徑）而非網頁的短URL。
- 在清單檢視中，當資產從Assets UI頁面（透過封裝管理程式除外）上傳或匯入時，已修改的欄會顯示「外部使用者」而非使用者名稱。
- 標題在地圖控制面板的主題索引標籤中無法正確顯示。
- 啟用節點平面化功能時，HTML輸出中會儲存一些不想要的垃圾字元。
- 使用者偏好設定中的資料夾設定檔變更不會針對已開啟的檔案自動重新載入，但瀏覽器需要重新整理。
- 如果發生某些驗證錯誤，透過「下載地圖」選項產生的輸出會遺漏一些主題。

## 第3.8發行版本的新功能與增強功能

### 檔案命名組態更新

在XML Documentation解決方案中建立DITA主題時，允許使用者使用特殊字元作為檔案名稱的一部分。 這會在產生AEM網站頁面上產生編碼URL。 為避免在URL中進行此轉換，XML Documentation解決方案的3.8版可讓管理員定義預設有效檔案名稱設定(a-z A-Z 0-9 - _)以外的特殊字元清單。 這表示雖然您可以在包含空格的檔案名稱中設定特殊字元清單，但清單將會取代為連字型大小(-)。

### AEM網站頁面名稱產生變更

在製作時，不同資料夾下的一個或多個檔案可能會有相同的檔案名稱。 在AEM網站發佈程式中，至少出現重複檔案名稱時，頁面名稱會附加尾碼。 XML Documentation解決方案3.8版修正AEM網站頁面名稱產生程式。 只有在檔案名稱重複時，才會將尾碼附加至產生的頁面名稱。

### 新功能和增強功能

產品的下列領域引進了許多新功能和增強功能。

#### 網頁編輯器

- 您現在可以在從Web編輯器建立主題版本時，從下拉式清單中選擇標籤。

  下拉式清單中的![標籤](assets/labels-drop-down-saving-topic-res.avif)

- 網頁編輯器中的稽核面板現在已變得更強大，使您能夠把主題還原成共用以供稽核的版本。 您可以輕鬆將稽核註釋併入稽核版本中，而無需記住要稽核的共用主題版本。

  ![還原主題以檢閱版本](assets/revert-review-topic.avif)

- 已引入新的視覺提示，以指示您使用的是最新版本的主題還是較早版本。

  ![版本提示](assets/old-version-icon.avif)

- 此發行版本已引入新的版本記錄功能。 使用「版本記錄」功能可以：
   - 檢視目前作用中主題所有版本的清單，以及為每個版本新增的標籤。
   - 回覆成主題先前的版本。

  ![版本記錄](assets/version-history.avif)

- 已新增新的「版本標籤管理」功能，可讓您將標籤套用至目前或舊版主題。

  ![版本標籤管理](assets/version-label-management.avif)

- 新增功能：「核准發佈」，作者可使用此功能將資產標示為已核准，並進一步鎖定資產以供編輯。
- 啟動稽核流程時，您現在可以根據主題的狀態來篩選主題。

  ![根據其狀態選取評論主題](assets/review-select-topic-on-state.avif)

- 地圖中的`<navtitle>`會自動填入新增至地圖檔案的主題標題。 您也可以從網頁編輯器輕鬆重新整理`<navtitle>`。
- 現在，預覽含有大量欄的表格會顯示於頁面區域中。
- 您可以從「屬性」面板（多重選取）一次套用多個輸出類別。
- 預覽主題時，您也可以直接從Web編輯器產生單一主題的（無條件） PDF輸出。

  來自預覽的![PDF輸出](assets/pdf-output-from-preview.avif)

- 如果輸出產生相同的預設集正在進行中，則封鎖發佈請求。
- 新增僅允許一組有特殊許可權的使用者刪除具有有效背景參照之資產的功能。
- 新增一項功能，可讓您從Assets UI的「Source檢視」檢視或複製XML程式碼，即使檔案已由其他使用者取出亦然。

  ![XML Source檢視](assets/xml-source-view-from-assets-ui.avif)

- 檔案名稱現在由「儲存」對話方塊、「可重複使用的內容」面板和「尋找及取代」面板中的檔案標題取代。

#### 發佈

- **允許設定已產生網站頁面的清理規則**：身為管理員，您可以為已產生AEM網站或DITA-OT輸出的檔案名稱定義清理規則。 每當您使用DITA-OT產生AEM Site輸出或輸出時，都可以設定以下規則來清理輸出產生的URL或檔案名稱：
   - 將所有字元轉換為小寫。
   - 以分隔符號取代特殊字元。
   - 將檔案名稱長度限製為預先定義的字元數。

- 使用大量啟動控制面板，輕鬆地將輸出從製作執行個體推送到發佈執行個體。 您可以處理單一地圖或地圖集合，並選擇您要用於發佈的輸出預設集。

  ![大量發佈儀表板](assets/bulk-publish-dashboard.avif)

#### 效能改良

- AEM Sites輸出的節點平面化：早期AEM Sites輸出的網站節點結構太深。 現在，您可以控制項來平面化節點結構，以提升效能。
- 支援最新版的FrameMaker Publishing Server 2020年夏季版。
- 現在會移除翻譯期間產生的暫存檔案，以改善翻譯程式。

#### 其他增強功能

- 已移除後處理DITA內容時DAM更新資產工作流程的相依性。 如果在DAM更新資產工作流程下定義了任何自訂流程步驟，您必須更新這些步驟，以便在後處理完成後執行。
- 翻譯程式發起人現在會在翻譯工作成功建立時，在其收件匣中收到通知。

### 錯誤修正

3.8版本中已修正的錯誤如下：

- 音訊物件不會顯示在HTML輸出中。
- 刪除DITA主題時顯示的強制刪除視窗會顯示多個「強制刪除」按鈕。
- 使用伺服器端檢視建立的基準線無法傳輸基準線至語言副本。
- 有時，主題的3.0版在並排檢視中會顯示為3，不允許匯入稽核註解。
- 針對已移動的DITA map，在「基準線」標籤上載入參考內容詳細資訊的速度緩慢。
- 回覆至舊版不適用於非dita資產。
- 使用AEM Sites輸出產生功能建立了許多空白的_text節點。
- XML編輯器 — 頁面產生後影像地圖中的連結解析度無法運作。
- 「基準線」標籤的「套用標籤」不會在參照的內容（如影像）上新增標籤。
- 透過「下載地圖」選項，以不正確的格式下載SVG檔案。
- 無法在清單檢視中編輯內容片段。
- 無法使用聯結器在Oxygon XML Author中籤出及開啟檔案。
- `<alt>`元素文字在編寫檢視中不可見。
- 即使存在翻譯的副本，影像資產仍一律顯示為「過期」。
- 自訂地圖範本標題不正確，不會顯示縮圖。
- 套用的品牌標誌元素不會顯示在網頁編輯器的製作檢視中。
- 連結的註腳不會顯示在內容中。
- 網頁編輯器中的色彩編碼無法搭配專門的條件屬性使用。
- @keyref的下拉式清單不方便使用，因為它對擁有大量使@keyref者的客戶幾乎無法使用。
- @keyref參考的變數文字不會轉譯。
- 氧氣聯結器 || 「在氧氣中編輯」按鈕現在會在編輯模式中開啟檔案，即使檔案未出庫亦然。
- 未使用自訂對應範本建立自訂輸出預設集。
- Microsoft Word (.docx)到DITA的轉換不會建立jcr:content節點，且允許資料夾名稱使用特殊字元。
- 移動MAP （參照超過150個）後，參照會中斷，並在開啟主題時觀察錯誤。
- 影像寬度變更時，無法正確計算影像的解析度。
- 在`<codeblock>`中新增影像時，在AEM網站輸出中找到不想要的空格。

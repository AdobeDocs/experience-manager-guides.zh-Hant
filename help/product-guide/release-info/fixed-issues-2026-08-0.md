# 2026.08.0版本中的已修正問題

本文章說明2026.08.0版Adobe Experience Manager Guides as a Cloud Service中不同區域所修正的錯誤。

如需新功能和增強功能的詳細資訊，請檢視[2026.08.0版的新增功能](whats-new-2026-08-0.md)。

瞭解2026.08.0版[&#128279;](upgrade-instructions-2026-08-0.md)的升級指示。

## 製作

- 從「地圖」控制面板的「主題」報表存取主題時，無法在編輯器中開啟主題。 (GUIDES-45277)


## 編輯器2.0

- 將MathML方程式插入為`conref`時，無法正確轉譯。 (GUIDES-46601)
- 在`<keydef>`或`<topicref>`內的`<topicmeta>`中複製並貼上`<keywords>`會導致關鍵字被插入不需要的外部標籤中。 (GUIDES-45800)
- 在地圖編輯器的中斷連結上使用`Ctrl+click`會觸發應用程式錯誤。 (GUIDES-45544)
- 從Excel試算表複製表格並將其貼到新編輯器時，會將所有複製的儲存格內容放入單一表格儲存格中，而不是將其分散到對應的儲存格中。 (GUIDES-47435)
- 透過`editor_toolbar.json`設定的自訂&#x200B;**匯出為PDF**&#x200B;按鈕會呈現在預覽模式中並保持可點按，但點按時不會執行任何動作。 (GUIDES-47402)
- MathML和SVG元素不會轉譯其完整的屬性集，導致套用至這些元素的自訂CSS類別和條件屬性中斷。 (GUIDES-46371)
- 開啟包含表格的某些主題時，會新增包含兩個新欄的未預期`<foreign>`標籤，即使未對主題進行任何變更亦然。 (GUIDES-46748)
- **Scale**&#x200B;屬性不適用於作者檢視中的影像。 (GUIDES-45996)
- 拖放包含`keyref`的元素會將`keyref`值轉換為絕對路徑。 (GUIDES-45701)
- 在`tgroup`位置插入元素會顯示此處不允許的&#x200B;**#text警告，以防止在該位置插入一般表格。**(GUIDES-47446)
- AEM拼字檢查器仍會標籤新增至字典的英數字元，而非予以忽略。 (GUIDES-48587)

## 資產管理

- 大量資產處理錯誤包含內容片段資產，導致處理報告中有錯誤記錄和失敗。 (GUIDES-47085)
- 在「對映」面板中，如果重複選取和取消選取對映核取方塊，子主題無法載入，展開圖示消失。 (GUIDES-43546)

## 發佈

**AEM Sites**

使用複合元件對應來發佈AEM Sites輸出時：

- 在具有複合元件對應的AEM Sites預設集中使用新基準線時，會顯示空白的&#x200B;**主題清單**。 (GUIDES-46480)
- 非DITA資產（例如PDF、ZIP、DOCX和影像檔案）的互動參照(`xref`)連結無法正確解析，導致產生頁面上的連結損毀。 (GUIDES-44108)

使用舊版元件對應來發佈AEM Sites輸出時：

- 產生的頁面名稱中的非英文檔案名稱會取代為連字型大小，因此很難識別與其相關聯的主題或檔案。 (GUIDES-48387)

**原生PDF**

- 在原生PDF輸出中，以`toc="no"`屬性標籤的主題參考仍會包含在目錄中，導致內容冗長且雜亂。 (GUIDES-37940， GUIDES-20156)

**對應集合與大量啟動**

下列問題已在Experience Manager Guides 2020.08.0版提供的[新地圖集合](../user-guide/generate-output-use-new-map-collection-output-generation.md#use-new-map-collection-for-output-generation-beta)功能中修正：

- 發生網路錯誤，因此無法載入包含超過100個對應專案的對應集合。 (GUIDES-34007)
- 無法從地圖收集UI的資料夾中一次選取多個地圖。 (GUIDES-29581)
- 無法在地圖集合UI中搜尋或篩選地圖集合。 (GUIDES-27723)
- 無法關閉大量發佈/啟動儀表板，或導覽回&#x200B;**工具**&#x200B;或首頁，而不使用瀏覽器的上一頁按鈕。 (GUIDES-26797)
- 無法輕易管理大量地圖或語言的地圖集合。 (GUIDES-21735)
- 無法直接從對應集合或大量啟用儀表板介面檢視或發佈產生的輸出。 (GUIDES-18712)
- 無法使用單一集合來產生和啟用對應，因為對應集合和大量啟用儀表板會管理個別的集合集。 (GUIDES-12730)

## 檢閱

- 在稽核UI中，標籤清單會顯示稽核任務中的所有使用者，這使得在評論或回覆中選取正確使用者變得困難。 (GUIDES-33420)
- 在「註解」面板中開啟&#x200B;**並排**&#x200B;檢視時，會將工作復本與註解版本一起顯示，但窗格不會以水準同步方式捲動，而且按一下註解也不會將游標移至對應的文字。 (GUIDES-44083)

## 資料庫

- `DatabaseConfiguratorService`在記錄中擲回錯誤，即使它未設定或啟用。 (GUIDES-43481)

## 已知問題

Adobe已找出下列2026.08.0版的已知問題：

## 製作

- 關閉已移至其他位置的DITAVAL檔案會產生`ERROR IN FETCHING VERSION DETAILS`錯誤訊息。 (GUIDES-51420)

## 編輯器2.0


- 當存放庫資料夾路徑以正斜線結尾時，衝突API會失敗並導致應用程式錯誤。 (GUIDES-51006)
- 在「大綱」檢視中選取處理指示元素會醒目顯示整個父標籤，而非選取的元素。 (GUIDES-48318)
- 在來源檢視中編輯`keyref`內的關鍵字，會在檢視切換至任何其他檢視時中斷該關鍵字。 (GUIDES-49998)
- 包在`foreign`和`equation`區塊內的MathML方程式會導致不必要的間距，且在方程式內輸入會導致即使在調整縮排後出現問題。 (GUIDES-46606)
- 啟用&#x200B;**顯示標籤**&#x200B;選項且編輯器設定中停用&#x200B;**顯示屬性**&#x200B;選項時，無法將游標置於`reltable`內的`topicref`內。 (GUIDES-46565)
- 將參考拖放至空白`keydef`會新增`topicref`專案，而非更新參考。 (GUIDES-45068)

## 發佈

- 在產生Edge Delivery Services輸出後選取&#x200B;**檢視輸出**&#x200B;會開啟傳回403禁止錯誤的`hlx.live` URL而非`aem.live` URL。 (GUIDES-51572)
- 從範本的工具列新增影像、超連結或iframe時，`common.plt`頁面上會顯示無效的元件。 (GUIDES-51165)
- 使用`copy-to`屬性發佈參照主題的對應時，會將對等範圍連結從來源對應的主題中移除。 (GUIDES-50701)
- 當PDF被引用為範圍設定為`Peer`的`xref`時，它發佈在AEM網站上（使用舊版元件對應），而不是從交叉對映取得。 (GUIDES-50213)

**對應集合**

- 如果您切換標籤（例如「存放庫」或「概觀」），然後返回「地圖集合」頁面再刪除它，刪除地圖集合有時會失敗。 (GUIDES-50997)
- 在上一代進行時產生相同的預設集，不再顯示訊息，指出正在進行上一代。 (GUIDES-50523)
- 產生地圖後，地圖收集UI中不會顯示或更新上次產生的時間戳記，重新新增先前已移除的預設集會導致其產生歷史記錄再次遺失。 (GUIDES-50511)
- 從&#x200B;**層代歷程記錄**&#x200B;發佈時，一律會發佈預設集的最新輸出，而非選取的層代。 (GUIDES-50508)
- 發佈狀態不會為新建立的對應集合自動重新整理。 (GUIDES-50367)

## 翻譯

- 以&#x200B;**僅建立結構**&#x200B;選項啟動轉譯會傳回錯誤。 (GUIDES-51261)

## 檢閱

- 使用鍵盤快速鍵對包含隱藏條件式內容的文字執行刪除線，也會刪除隱藏的內容。 (GUIDES-49837)

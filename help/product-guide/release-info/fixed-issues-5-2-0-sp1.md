# 已修正5.2.0 Service Pack 1版本（2026年9月）中的問題

本文章說明5.2.0 Service Pack 1版本不同區域所修正的Adobe Experience Manager Guides錯誤。

瞭解5.2.0 Service Pack 1版本[&#128279;](upgrade-instructions-5-2-0-sp1.md)的升級指示。

## 製作

- 在低解析度熒幕上，從工具列插入關鍵字時，[插入關鍵字]對話方塊無法顯示，而使用&#x200B;**更多**&#x200B;選項時，對話方塊會如預期般開啟。 (GUIDES-48304)
- 使用&#x200B;**網頁連結**&#x200B;選項插入互動參照，會新增`scope=local`連結並修改`href`值，而非如預期插入`scope=external`連結。 (GUIDES-48457)
- 儲存參考地圖會導致參照中斷，而不是當一個作者移動參考地圖而另一個作者同時在未儲存的地圖中新增對它的參照時，解析為正確的地圖。 (GUIDES-47467)
- AEM拼字檢查器仍會標籤新增至字典的英數字元，而非予以忽略。 (GUIDES-48587)
- 使用單位大小（例如`in`、`mm`或`px`）在影像屬性對話方塊中的&#x200B;**寬度**&#x200B;和&#x200B;**高度**&#x200B;欄位之間切換焦點時，值會遞增而非保持穩定。 (GUIDES-45929)

## 編輯器2.0

- 刪除資料表儲存格`<entry>`內緊鄰內嵌標籤之前輸入的空白字元。 (GUIDES-49144)
- 在`tgroup`位置插入元素會顯示此處不允許的&#x200B;**#text警告，以防止在該位置插入一般表格。**(GUIDES-47446)
- 從Excel試算表複製表格並將其貼到新編輯器時，會將所有複製的儲存格內容放入單一表格儲存格中，而不是將其分散到對應的儲存格中。 (GUIDES-47435)
- 透過`editor_toolbar.json`設定的自訂&#x200B;**匯出為PDF**&#x200B;按鈕會呈現在預覽模式中並保持可點按，但點按時不會執行任何動作。 (GUIDES-47402)
- 開啟包含表格的某些主題時，會新增包含兩個新欄的未預期`<foreign>`標籤，即使未對主題進行任何變更亦然。 (GUIDES-46748)
- 將MathML方程式插入為`conref`時，無法正確轉譯。 (GUIDES-46601)
- MathML和SVG元素不會轉譯其完整的屬性集，導致套用至這些元素的自訂CSS類別和條件屬性中斷。 (GUIDES-46371)
- **Scale**&#x200B;屬性不適用於作者檢視中的影像。 (GUIDES-45996)
- 套用`scale`屬性至資料表時，在製作和預覽模式中不會以設定的大小轉譯資料表。 (GUIDES-45984)
- 貼上從外部來源（如「油漆」或「剪裁工具」）複製的影像時，不會將影像插入主題。 (GUIDES-45983)
- 在`<keydef>`或`<topicref>`內的`<topicmeta>`中複製並貼上`<keywords>`會導致關鍵字被插入不需要的外部標籤中。 (GUIDES-45800)
- 在表格的「標籤」檢視中，當游標位於縮疊專案標籤正下方的儲存格時，按向上鍵可跳過縮疊的標籤，並將游標移至檔案的開頭。 (GUIDES-45408)
- 從表格內容工具列執行任何操作時，會意外關閉工具列，中斷後續的表格操作。 (GUIDES-45405)
- **編輯MathML**&#x200B;選項在唯讀模式下或檔案已由其他使用者取出時無法正確顯示，即使檔案不應為可編輯狀態，仍可讓使用者更新MathML內容。 (GUIDES-45172)
- 從大綱檢視或階層連結使用&#x200B;**插入在後**&#x200B;或&#x200B;**插入在前**&#x200B;之後，游標會移至任意位置而不是新新增的標籤內。 (GUIDES-45147)
- 在啟用「標籤」檢視的情況下執行拖放時，選取內容連同部分XML或DITA標籤會留下不想要的孤立標籤，導致不正確的內容或檢視。 (GUIDES-28191)

## 資產管理

- 在多種情況下，版本清除公用程式無法完成，包括特定檔案型別、遺失中繼資料的資產和大型報表，而無法完成清除並產生準確的報表。 (GUIDES-43453)

## 發佈

- 產生的頁面名稱中的非英文檔案名稱會取代為連字型大小，使得在使用舊版元件對應發佈AEM Sites輸出時，難以識別其所關聯的主題或檔案。 (GUIDES-48387)
- 已識別DITA-OT套件中與AEM Guides搭配的易受攻擊的`jackson-databind`個JAR （2.9.8版）。 (GUIDES-43081)

## 檢閱

- 在「註解」面板中開啟&#x200B;**並排**&#x200B;檢視時，會將工作復本與註解版本一起顯示，但窗格不會以水準同步方式捲動，而且按一下註解也不會將游標移至對應的文字。 (GUIDES-44083)

## Platform

- 使用`scope="external"`作為主題或地圖中DAM內容的參照會導致資產的相對路徑被GUID取代。 (GUIDES-35605)
- 針對UUID移轉前建立的內容，下載包含&#x200B;**保留檔案階層**&#x200B;和&#x200B;**使用實際檔案名稱**&#x200B;選項的地圖，會將`topicref`、`xref`和`conref`元素的`href`個值（包含`scope="external"`）錯誤地轉換為GUID型檔案名稱，而非保留原始的相對檔案路徑。 因此，外部參照會中斷。 (GUIDES-46526)
- 透過Assets UI上傳資產時，不會顯示上傳狀態。 （指南–7207）

## 已知問題

- 在程式碼區塊內執行檢閱作業時，第一次嘗試時會顯示&#x200B;**不允許的作業**&#x200B;警告，但若重複則作業會成功。 (GUIDES-56749)
- 為包含`code block`的內容建立稽核任務時，匯入後刪除線格式無法正確套用，且並排比較檢視中缺少醒目提示的內容。 (GUIDES-56811)
- 在某些情況下，即使地圖包含多個主題，「報表」面板中的&#x200B;**主題清單**&#x200B;索引標籤也不會顯示任何結果。 (GUIDES-56893) <br> **因應措施：**&#x200B;重新索引受影響的內容以重建父對映關係。 主題會依預期顯示在「主題清單」標籤中。
- 在「大綱」檢視中選取處理指示元素會醒目顯示整個父標籤，而非選取的元素。 (GUIDES-48318)
- 執行刪除操作時，可能會在影像地圖、結構化元素、內嵌格式標籤及不可合併的區塊之間發生游標移動和導覽的一些細微不一致，有時會導致意外的游標或刪除行為。 (GUIDES-46756)
- 包在`foreign`和`equation`區塊內的MathML方程式會導致不必要的間距，且在方程式內輸入會導致即使在調整縮排後出現問題。 (GUIDES-46606)
- 啟用&#x200B;**顯示標籤**&#x200B;選項且編輯器設定中停用&#x200B;**顯示屬性**&#x200B;選項時，無法將游標置於`reltable`內的`topicref`內。 (GUIDES-46565)
- 在唯讀內容（例如conref段落）之後緊鄰的段落開頭按退格鍵，可能會意外刪除或合併可編輯的段落，導致意外刪除可編輯的段落。 (GUIDES-45049)
- 當使用重新命名元素選項重新命名內嵌標籤時，階層連結不會立即更新，且只會在游標移至標籤或檢視模式變更後反映變更。 (GUIDES-44993)<br>**因應措施：**&#x200B;重新命名內嵌標籤以更新階層連結後，請重新整理瀏覽器。
- 將條件指示器套用至bodydiv等元素時，指示器會溢滿至「完整標籤檢視」中的相鄰標籤，導致不正確的視覺呈現。 (GUIDES-44971)

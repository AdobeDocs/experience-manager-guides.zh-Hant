# 2026.09.0版中的已修正問題

本文介紹2026.09.0版Adobe Experience Manager Guides as a Cloud Service中不同區域修正的錯誤。

如需新功能和增強功能的詳細資訊，請檢視[2026.09.0版的新增功能](./whats-new-2026-09-0.md)。

瞭解2026.09.0版](./upgrade-instructions-2026-09-0.md)的[升級指示。

## 編輯器2.0

- 從製作模式複製資料表並將其貼到製作模式，會移除`colwidth`等屬性以及在`colspec`上定義的任何其他屬性，導致欄寬設定遺失。 (GUIDES-52916)
- 刪除資料表儲存格`<entry>`內緊鄰內嵌標籤之前輸入的空白字元。 (GUIDES-49144)

## 製作

本節涵蓋Editor 1.0和Editor 2.0在撰寫中常見的錯誤。

- 在低解析度熒幕上，當從工具列插入關鍵字時，[插入關鍵字]對話方塊無法顯示，當使用&#x200B;**更多**&#x200B;選項時，對話方塊會如預期般開啟。 (GUIDES-48304)
- 在Schematron驗證設定空白規則檔案時儲存主題會顯示不準確、一般性的錯誤訊息。 (GUIDES-48106)
- 使用文位元組點內容的結構描述規則不會觸發驗證。 (GUIDES-14500)
- 使用&#x200B;**網頁連結**&#x200B;選項插入互動參照，會新增`scope=local`連結並修改`href`值，而非如預期插入`scope=external`。 (GUIDES-48457)
- 儲存參考地圖會導致參照中斷，而不是當一個作者移動參考地圖而另一個作者同時在未儲存的地圖中新增對它的參照時，解析為正確的地圖。 (GUIDES-47467)

## 資產管理

- 資產狀態API不會針對路徑包含逗號的資產傳回正確狀態。 (GUIDES-49065)
- Assets管理員搜尋邊欄中的DITA元素篩選器不會套用輸入的值，因此搜尋結果不會經過篩選。 (GUIDES-48450)
- 在多種情況下，版本清除公用程式無法完成，包括特定檔案型別、遺失中繼資料的資產和大型報表，而無法完成清除並產生準確的報表。 (GUIDES-43453)
- 在Assets UI中使用「移動」操作，將具有GUID型檔案名稱的資產重新命名為其他GUID，並以新的GUID取代資產的原始唯一GUID。 (GUIDES-43006)

## 發佈

- 當您產生具有基準線（鎖定較舊版本）的AEM Sites （具有複合元件對應）輸出時，頁面內容會正確顯示較舊的版本，但頁面中繼資料會顯示目前的版本。 (GUIDES-49325)
- 使用大量啟動來復寫頁面時，復寫追蹤屬性只會在根頁面上設定，而不會在子頁面上設定，因此難以判斷自上次復寫以來變更了哪些內容。 (GUIDES-37871)
- 當「建立/編輯基準線」對話方塊中的&#x200B;**標籤**&#x200B;欄位第一次收到焦點時，貼上或輸入第一個字元無法正確篩選自動完成建議，而且欄位會顯示所有建議而非篩選的結果。(GUIDES-50143)
- 分支篩選會針對用作`keydef`的不想要的主題產生額外頁面（這些主題已由DITA-OT標籤`resource-only ="true"`）。 (GUIDES-19701)
- 對應集合為尚未產生的預設集啟用&#x200B;**發佈**&#x200B;選項。 (GUIDES-50510)
- 當新建立的對應集合沒有發佈記錄時，發佈記錄區段不會顯示預留位置文字。 (GUIDES-50366)
- 在原生PDF預設集上套用ICC色彩設定檔會導致輸出產生失敗，而且即使使用直接設定檔路徑，CMYK色彩也不會正確呈現。 (GUIDES-47137)
- 原生PDF預設集上設定的出血設定不會反映在產生的輸出中。 (GUIDES-47034)
- 資料表繼續的&#x200B;**分隔符號前的文字**&#x200B;欄位只會轉譯當地語系化的字串，而不會取代頁碼預留位置。 (GUIDES-32872)
- ICC設定檔瀏覽器無法正確顯示DITA檔案，而非僅顯示ICC檔案。 (GUIDES-25017)
- 原生PDF輸出中未轉譯草稿註解。 (GUIDES-47044)
- 置於`title`元素內的草稿註解意外出現在已發佈的輸出中。 (GUIDES-10686)
- 在「地圖」控制面板中，選取不同的預設集時會觸發呼叫以擷取同級連結，導致額外的處理。 (GUIDES-53703)

## 翻譯

- 使用XLIFF專案開始翻譯時，會建立永遠不會變成進行中狀態的空白專案。 (GUIDES-51759)
- 使用資產移動作業將內容從某個語言資料夾移至另一個語言資料夾，會使作者無法在「翻譯」面板中選取要翻譯的內容。 (GUIDES-49386)
- 使用「**新增至現有翻譯專案**」選項傳送要翻譯的資產，而相同專案的其他翻譯請求（建立新專案或是&#x200B;*新增至現有*&#x200B;請求）仍在處理中，導致衝突。 (GUIDES-49354)

## 基準線

- 刪除基準線後或仍在建立動態基準線時，預設集儲存的基準線選取範圍錯誤地顯示為&#x200B;*無基準線*。 (GUIDES-52690)

## 檢閱

- 開啟稽核面板或套用專案篩選器需要一些時間才能載入任務清單。 (GUIDES-48893)

## 報告

- 針對包含大量主題的地圖產生「中斷連結」報表，會導致報表介面持續卡在&#x200B;**擷取中斷連結的詳細資料**&#x200B;訊息，無限期導致瀏覽器無回應，並最終導致其當機。 (GUIDES-37845)

## 學習內容

- 使用具有自訂標題的HTML或學習範本建立新學習主題時，主題標題未出現在自訂標題中。 (GUIDES-52343)
- 課程測驗的計算準確度百分比與預期值稍有不同。 (GUIDES-52346)
- 對於課程，在嘗試測驗時，分數與預期的計算分數略有不同。 (GUIDES-52345)

## 已知問題

Adobe已找出下列2026.09.0版的已知問題：

- 變更已鎖定主題的檔案狀態會重新整理整個檔案。 (GUIDES-53905)
- 使用基線功能預覽時，大型地圖（超過10,000個主題）或高數量`keydefs`的地圖的預覽要求逾時（例如100 `keydefs`和3,500個主題）。 (GUIDES-54147)
- 對於資料庫伺服器，當包含不含`href`的`keydef`的地圖在啟用[使用基準線預覽]選項的情況下被預覽時，`keydef`無法解析。 (GUIDES-53878)
- 在影像地圖資產上設定的熱點區域在預覽模式中不是互動式，使作者無法在發佈前驗證熱點連結。 (GUIDES-53398)<br>**因應措施**：插入您要轉換成影像地圖的影像，從內容功能表選取&#x200B;**編輯影像地圖**，然後設定熱點連結。
- 當您在地圖開啟時將具有現有基準線的地圖移至其他資料夾時，使用基準線&#x200B;**的**&#x200B;預覽切換功能在預覽模式中仍保持選取狀態，但基準線不再出現在下拉式清單中。 (GUIDES-54284)<br>**因應措施**：您可以關閉並重新開啟地圖來解決問題。
- 在新設定的AEM Cloud Service環境(AEM as a Cloud Service SDK)上，嘗試建立地圖或主題檔案會導致&#x200B;*無法建立檔案*&#x200B;錯誤或&#x200B;*擷取DTD規則時發生錯誤*。 (GUIDES-53904)<br>**因應措施**：您可以重新啟動AEM Cloud Service環境。
- 當兩個作者同時處理相同主題時，鎖定已由某位作者開啟了一段時間的主題，不會重新整理中繼資料屬性，例如版本編號、標籤、檔案狀態、標籤等，即使其他作者已變更這些屬性，導致繼續顯示過時的值。 (GUIDES-54810)<br>**因應措施**：關閉並重新開啟主題，以重新整理中繼資料並顯示最新的值。

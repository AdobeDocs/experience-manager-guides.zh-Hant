# 設定SCORM輸出預設集

建立預設集後，請配置SCORM預設集設定。 預設集組態選項會整理在「一般」、「內容」、「學習者體驗」和「發佈」標籤下。

- **一般：**&#x200B;用於指定基本輸出設定，例如支援的版本、輸出路徑、SCORM檔案名稱(zip)、輸出範本，以及包含所有已設定工作流程的新後置產生工作流程下拉式清單的後置產生工作流程。

  ![](assets/scorm-general-tab-v3.png){width="650"}


- **內容：**&#x200B;使用指定可用的條件篩選（使用DITAVAL或使用某些條件預設集）和變數集。

  ![](assets/scorm-content-tab.png){width="650"}

- **學習者體驗：** **學習者體驗**&#x200B;索引標籤可讓您設定學習者如何與SCORM輸出互動及導覽。 設定是以&#x200B;**一般**、**導覽**&#x200B;和&#x200B;**測驗**&#x200B;來整理，可讓您控制內容存取能力、導覽流程及測驗行為，以提供量身打造的學習體驗。

  ![](assets/learner-experience.png){width="650"}

  - **一般：**&#x200B;設定輸出層級選項，例如為學習者啟用PDF下載。

    - **允許學習者下載課程PDF**：啟用後，此選項會將PDF圖示新增至SCORM輸出。 按一下此圖示可讓學習者直接從發佈的輸出下載課程內容的PDF版本。

      **必要條件：**&#x200B;啟用此選項之前，請先確定下列事項：

      - **輸出範本**&#x200B;必須在所要的位置設定&#x200B;**內嵌PDF**&#x200B;圖示，且在設定SCORM預設集時，應在&#x200B;**一般**&#x200B;標籤的&#x200B;**輸出範本**&#x200B;選項下選取相同的範本。

        ![](assets/embed-pdf.png){width="650"}

      - 相關的&#x200B;**原生PDF預設集**&#x200B;必須已產生至少一次。 選取未產生的PDF預設集會導致錯誤，提示使用者發佈預設集。

    使用上述設定產生SCORM輸出後，產生的輸出會包含PDF圖示（如下所示），讓學習者可下載課程PDF。

    ![](assets/pdf-icon.png){width="650"}

  - **導覽：**&#x200B;定義學習者如何在課程中移動，包括循序漸進、強制完成條件，以及解鎖&#x200B;**下一步**&#x200B;按鈕的規則。

    - **學習者必須依循序進行內容**：確保學習者會依固定順序進行課程，而且不能跳過或跳到課程元件之間。
    - **如果學習者未通過測驗，則停用下一個按鈕**：阻止學習者移動到下一個區段/頁面，直到他們通過測驗。
    - **學習者必須嘗試所有問題才能繼續**：要求學習者先嘗試所有問題，才能提交測驗，以防止提交不完整的試卷。
    - **鎖定進度直到完成**：停用課程中的&#x200B;**下一步**&#x200B;按鈕，直到滿足其下所有設定的子條件為止，防止導覽整個課程。
      - **所有開啟的互動式元素**：需要學習者開啟頁面上的每個互動式元素。
      - **所有觀看過的媒體**：需要學習者觀看頁面上的所有視訊/音訊媒體。
      - **嘗試的所有知識檢查**：要求學習者嘗試頁面上的每個知識檢查問題。
      - **頁面**&#x200B;的最短逗留時間：在啟用「下一步」按鈕之前，學習者必須在頁面上至少停留指定的期間。 啟用後，您必須輸入下列所需的時間。
        - **所需時間（秒）**：學習者必須在頁面上停留的最小秒數（例如`30`），才能符合此條件。

  - **測驗：**&#x200B;設定測驗相關行為，例如隨機排列問題順序和答案選擇，以降低每次嘗試時的可預測性。

    - **隨機排列每次嘗試的問題順序**：以不同的順序顯示每次嘗試的測驗問題，有助於降低可預測性。
    - **隨機選擇每個嘗試的答案**：隨機選擇每個嘗試的答案選項，減少猜測的機會。

- **發佈至LMS：**&#x200B;使用此設定直接將您的內容發佈至Adobe Learning Manager (ALM)。 從&#x200B;**發佈伺服器**&#x200B;下拉式清單中，選取&#x200B;**Adobe Learning Manager**，然後選擇先前在Workspace設定中設定的必要&#x200B;**發佈設定檔**。 選取的設定檔可用來建立連線，並將產生的內容上傳至ALM。

  >[!NOTE]
  >
  > 將內容發佈至ALM之前，您必須先設定Adobe Learning Manager發佈設定檔。 如需詳細資訊，請檢視[發佈設定檔](../lc-config-guide/lc-folder-profile.md)。

  ![](assets/scorm-publish-lms.png){width="650"}

設定好所有變更後，請使用SCORM預設集頁面工具列右角的&#x200B;**儲存**，儲存SCORM預設集的變更。
